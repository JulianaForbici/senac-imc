# 🧮 Calculadora de IMC (PHP + HTML)

## 📘 Descrição
Este projeto é uma **calculadora de IMC (Índice de Massa Corporal)** desenvolvida em **PHP e HTML**, com foco educacional.  
O sistema recebe o **peso** e a **altura** do usuário, calcula o IMC e retorna a **classificação** (Magreza, Saudável, Sobrepeso, Obesidade, etc.) conforme os critérios da **Organização Mundial da Saúde (OMS)**.

---

## 🧰 Tecnologias utilizadas
- 🐘 **PHP 8.3+**
- 🧱 **HTML5 / CSS3 / JavaScript**
